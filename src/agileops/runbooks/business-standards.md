# Reporting restoration acceptance criteria

A dashboard refresh repair must load the approved source fixture, reconcile order counts and integer-cent totals per region, and preserve the last successful snapshot when a refresh fails. Record the correlation ID and attach test evidence. Obtain approval for priority, scope, changes and release before applying a consequential remediation.
